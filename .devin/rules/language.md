description: Enforce English as the only language for all project content
---

All content in this repository MUST be written in English only. This rule applies to:

- Documentation files (README.md, TESTING.md, and any other .md files)
- CI/CD pipeline files (GitHub Actions workflows, job names, step names, and inline comments)
- Code comments and docstrings
- Commit messages
- Any other text content added to the repository

Never generate French (or any other non-English language) text in any of the above contexts.
